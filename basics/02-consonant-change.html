01

음운 변동이란?

어떤 음운이 환경에 따라 다른 음운으로 바뀌거나, 없어지거나, 새로 생기는 현상을 음운 변동이라 한다. '국물'이 [궁물]로 발음되는 것은 받침 'ㄱ'이 뒤의 비음 'ㅁ'의 영향으로 'ㅇ'으로 바뀐 것이다.

유형정의예
교체(대치)한 음운이 다른 음운으로 바뀜국물[궁물]
탈락한 음운이 없어짐닭[닥]
첨가없던 음운이 새로 생김솜이불[솜니불]
축약두 음운이 합쳐져 하나로 줄어듦좋다[조타]
02

음절의 끝소리 규칙(교체)

국어는 음절 끝에서 'ㄱ,ㄴ,ㄷ,ㄹ,ㅁ,ㅂ,ㅇ' 일곱 자음만 발음된다. 나머지 받침은 이 중 하나의 대표음으로 바뀐다.

받침 표기대표음예
ㄲ, ㅋ[ㄱ]밖[박], 부엌[부억]
ㅅ, ㅆ, ㅈ, ㅊ, ㅌ, ㅎ[ㄷ]옷[옫], 있다[읻따], 낮[낟], 꽃[꼳], 밭[받]
ㅍ[ㅂ]잎[입]
03

소리의 동화(교체)

비음화

받침 'ㄱ,ㄷ,ㅂ'이 비음 'ㄴ,ㅁ' 앞에서 비음 'ㅇ,ㄴ,ㅁ'으로 바뀐다. 'ㄱ,ㅂ' 뒤에 'ㄹ'이 오면 'ㄹ→ㄴ'이 되며 앞자음도 비음화된다.

변동 환경예발음
ㄱ+ㄴ/ㅁ → ㅇ+ㄴ/ㅁ국물, 먹는다[궁물], [멍는다]
ㄷ+ㄴ/ㅁ → ㄴ+ㄴ/ㅁ닫는다, 받는다[단는다], [반는다]
ㅂ+ㄴ/ㅁ → ㅁ+ㄴ/ㅁ밥물, 잡는다[밤물], [잠는다]
ㄱ,ㅂ+ㄹ → ㅇ,ㅁ+ㄴ독립, 협력[동닙], [혐녁]

유음화

비음 'ㄴ'이 유음 'ㄹ'의 앞이나 뒤에서 'ㄹ'로 바뀐다.

변동 환경예발음
ㄹ+ㄴ → ㄹ+ㄹ (순행)칼날, 달나라[칼랄], [달라라]
ㄴ+ㄹ → ㄹ+ㄹ (역행)신라, 천리[실라], [철리]
예외. '의견란, 생산량'처럼 일부 한자어는 유음화 없이 [ㄴ]으로 발음한다(의견란[의견난], 생산량[생산냥]).

구개음화

받침 'ㄷ,ㅌ'이 형식 형태소 '이'와 만나면 'ㅈ,ㅊ'으로 바뀌어 뒤 음절 첫소리로 옮겨 발음된다.

변동 환경예발음
ㄷ + 이 → 지굳이[구지]
ㅌ + 이 → 치밭이, 같이[바치], [가치]
ㄷ + 히 → 치(축약 결합)닫히다[다치다]
주의. 구개음화는 형식 형태소 '이/히'와 결합할 때만 일어난다. 실질 형태소 앞에서는 일어나지 않는다(밭이랑[반니랑] — 구개음화 아님, 'ㄴ' 첨가+비음화).
04

된소리되기(교체)

예사소리 'ㄱ,ㄷ,ㅂ,ㅅ,ㅈ'이 일정 환경에서 된소리 'ㄲ,ㄸ,ㅃ,ㅆ,ㅉ'으로 바뀐다.

환경예발음
안울림 받침(ㄱ,ㄷ,ㅂ 등) 뒤국밥, 학교, 옆집[국빱], [학꾜], [엽찝]
용언 어간 받침 'ㄴ,ㅁ' 뒤신다, 감다[신ː따], [감ː따]
관형사형 어미 '-(으)ㄹ' 뒤할 것, 갈 데[할껃], [갈떼]
한자어 'ㄹ' 받침 뒤 ㄷ,ㅅ,ㅈ물질, 발달[물찔], [발딸]
05

축약·탈락·첨가

거센소리되기(축약)

'ㅎ'과 예사소리 'ㄱ,ㄷ,ㅂ,ㅈ'이 만나면 거센소리 'ㅋ,ㅌ,ㅍ,ㅊ'으로 축약된다. 'ㅎ'이 앞이든 뒤든 상관없이 일어난다.

결합예발음
ㅎ+ㄱ → ㅋ / ㅎ+ㄷ → ㅌ좋고, 좋다[조코], [조타]
ㄱ+ㅎ → ㅋ / ㅂ+ㅎ → ㅍ국화, 입학[구콰], [이팍]
ㅈ+ㅎ, ㅎ+ㅈ → ㅊ맞히다, 좋지[마치다], [조치]

자음군 단순화(탈락)

겹받침 중 하나가 탈락하고 하나만 발음된다.

겹받침탈락 규칙예발음
ㄳ,ㄵ,ㄽ,ㄾ,ㅄ 등대부분 뒤 자음 탈락몫, 앉다, 여덟, 없다[목],[안따],[여덜],[업ː따]
ㄺ원칙 ㄱ만 발음, 'ㄱ' 앞에서는 ㄹ만 발음닭, 흙, 맑고[닥],[흑],[말꼬]
ㄻㅁ만 발음삶, 젊다[삼ː],[점ː따]
ㄼ원칙 ㄹ만 발음, '밟-'은 예외적으로 ㅂ만 발음여덟 / 밟다[여덜] / [밥ː따]

'ㅎ' 탈락

어간 받침 'ㅎ(ㄶ, ㅀ 포함)'이 모음으로 시작하는 어미·접사와 만나면 'ㅎ'이 탈락한다.

환경예발음
ㅎ + 모음 어미낳아, 좋은, 많아[나아], [조은], [마ː나]

'ㄴ' 첨가

합성어·파생어에서 앞말이 자음으로 끝나고 뒷말이 '이,야,여,요,유'로 시작하면 'ㄴ' 소리가 새로 덧붙는다.

환경예발음
자음 + 이/야/여/요/유솜이불, 한여름, 색연필[솜니불], [한녀름], [생년필]
'ㄴ' 첨가 후 유음화가 겹치는 경우물약[물략]
참고. 'ㄴ' 첨가는 단어마다 정해져 있어 항상 일어나는 것은 아니므로 사전으로 확인하는 습관이 필요하다.
06

전체 정리

유형변동내용
교체음절의 끝소리 규칙받침이 7개 대표음(ㄱㄴㄷㄹㅁㅂㅇ)으로 바뀜
교체비음화ㄱ,ㄷ,ㅂ이 비음 앞에서 ㅇ,ㄴ,ㅁ으로 바뀜
교체유음화ㄴ이 ㄹ의 앞/뒤에서 ㄹ로 바뀜
교체구개음화ㄷ,ㅌ이 형식 형태소 '이'와 만나 ㅈ,ㅊ으로 바뀜
교체된소리되기예사소리가 특정 환경에서 된소리로 바뀜
축약거센소리되기ㅎ과 ㄱ,ㄷ,ㅂ,ㅈ이 합쳐져 ㅋ,ㅌ,ㅍ,ㅊ이 됨
탈락자음군 단순화겹받침 중 하나가 탈락
탈락'ㅎ' 탈락어간 받침 ㅎ이 모음 어미 앞에서 탈락
첨가'ㄴ' 첨가합성어·파생어에서 ㄴ 소리가 새로 생김
07

확인 문제

단어의 표준 발음과 적용된 자음 변동을 생각해 본 뒤 문제를 클릭해 정답을 확인하세요.

①앞마당
[암마당] — 음절의 끝소리 규칙(ㅍ→ㅂ) + 비음화(ㅂ→ㅁ)
②신라
[실라] — 유음화
③굳히다
[구치다] — 거센소리되기(ㄷ+ㅎ→ㅌ) 후 구개음화(ㅌ→ㅊ)
④값지다
[갑찌다] — 자음군 단순화(ㅄ→ㅂ) + 된소리되기
⑤맏이
[마지] — 구개음화
⑥놓지
[노치] — 거센소리되기(축약)
⑦닭장
[닥짱] — 자음군 단순화(ㄺ→ㄱ) + 된소리되기
⑧꽃잎
[꼰닙] — 음절의 끝소리 규칙(ㅊ→ㄷ) + 'ㄴ' 첨가 + 비음화(ㄷ→ㄴ)
⑨좋아
[조아] — 'ㅎ' 탈락
⑩한여름
[한녀름] — 'ㄴ' 첨가
해설. '꽃잎'처럼 두 가지 이상의 변동이 겹쳐 일어나는 단어는 순서가 중요하다. 먼저 음절의 끝소리 규칙이 적용되고, 그다음 'ㄴ' 첨가, 마지막으로 비음화가 순차적으로 일어난다.
