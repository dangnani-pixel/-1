01

모음 변동이란?

모음으로 끝나는 어간에 모음으로 시작하는 어미가 결합할 때, 모음과 모음이 부딪히는 것을 피하려고 한쪽 모음이 없어지거나(탈락), 반모음으로 바뀌거나(교체), 또는 두 모음 사이에 반모음이 끼어드는(첨가) 현상이 나타난다.

유의할 점은 반모음이 끼어드는 두 현상, 반모음화와 반모음 첨가는 서로 다른 현상이라는 것이다. 반모음화는 단모음이 반모음으로 바뀌는 것이므로 음운의 개수가 그대로지만, 반모음 첨가는 반모음이 새로 하나 더 생기는 것이므로 음운의 개수가 늘어난다.

02

모음 탈락

어간의 끝 모음이 어미의 첫 모음과 같거나 비슷한 성질일 때, 어간의 모음이 탈락한다.

동일 모음 탈락

어간 끝 모음 'ㅏ/ㅓ'와 어미의 첫 모음 'ㅏ/ㅓ'가 같을 때 어느 한쪽이 탈락한다.

기본형활용발음
가- + -아서가서[가서]
서- + -어도서도[서:도]
건너- + -어건너[건너]

'ㅡ' 탈락

어간 끝 모음 'ㅡ'가 어미 '-아/-어' 앞에서 탈락한다.

기본형활용발음
쓰- + -어써[써]
담그- + -아담가[담가]
고프- + -아서고파서[고파서]
크- + -어서커서[커서]
03

반모음화 (교체)

어간 끝의 단모음 'ㅗ/ㅜ/ㅣ'가 뒤에 오는 어미의 모음과 만나 반모음 [w]나 [j]로 바뀌면서 두 음절이 한 음절로 줄어든다. 음운이 하나 없어지는 것이 아니라 다른 음운(반모음)으로 바뀌는 것이므로 '교체'에 해당한다.

기본형활용발음변동
오- + -아서와서[와서]ㅗ→[w]
두- + -어둬[둬:]ㅜ→[w]
가리키- + -어가리켜[가리켜]ㅣ→[j]
다니- + -어서다녀서[다녀서]ㅣ→[j]
04

반모음 첨가

어간이 'ㅣ, ㅚ'로 끝나고 어미 '-어'가 결합할 때, 표준 발음법 제22항에 따라 두 모음 사이에 반모음 [j]를 첨가하여 [여]로 발음하는 것도 허용한다.

표기원칙 발음허용 발음(첨가)
피어[피어][피여]
되어[되어][되여]
이오[이오][이요]
아니오[아니오][아니요]
비교. '오+아서→와서'는 어간 모음 자체가 반모음으로 바뀌어 표기까지 달라지는 반모음화이고, '피어→[피여]'는 표기(피어)는 그대로 둔 채 발음에서만 반모음이 하나 더 끼어드는 반모음 첨가이다. 전자는 음운 개수가 그대로이지만, 후자는 음운 개수가 하나 늘어난다.
05

표준 발음법으로 보는 모음 발음 규정

표준어 규정 제2부 표준 발음법(문화체육관광부 고시)의 관련 조항. 항목을 눌러 원문을 확인하세요.

제4항 — 단모음
'ㅏ ㅐ ㅓ ㅔ ㅗ ㅚ ㅜ ㅟ ㅡ ㅣ'는 단모음으로 발음한다. [붙임] 'ㅚ, ㅟ'는 이중 모음으로 발음할 수 있다.
제5항 — 이중 모음
'ㅑ ㅒ ㅕ ㅖ ㅘ ㅙ ㅛ ㅝ ㅞ ㅠ ㅢ'는 이중 모음으로 발음한다.
다만 1. 용언의 활용형에 나타나는 '져, 쪄, 쳐'는 [저, 쩌, 처]로 발음한다.
다만 2. '예, 례' 이외의 'ㅖ'는 [ㅔ]로도 발음한다.
다만 3. 자음을 첫소리로 가지고 있는 음절의 'ㅢ'는 [ㅣ]로 발음한다.
다만 4. 단어의 첫음절 이외의 '의'는 [ㅣ]로, 조사 '의'는 [ㅔ]로 발음함도 허용한다.
제22항 — 용언 어미의 반모음 첨가
다음과 같은 용언의 어미는 [어]로 발음함을 원칙으로 하되, [여]로 발음함도 허용한다. 피어[피어/피여], 되어[되어/되여] [붙임] '이오, 아니오'도 이에 준하여 [이요, 아니요]로 발음함을 허용한다.
06

전체 정리

유형내용
동일 모음 탈락어간 끝 'ㅏ/ㅓ'가 어미의 동일 모음 앞에서 탈락 — 가- + -아서 → 가서
'ㅡ' 탈락어간 끝 'ㅡ'가 어미 '-아/-어' 앞에서 탈락 — 쓰- + -어 → 써
반모음화 (교체)어간 끝 단모음이 반모음 [w]/[j]로 바뀌며 한 음절로 축소 — 오- + -아서 → 와서
반모음 첨가어간이 'ㅣ, ㅚ'로 끝날 때 어미 사이에 [j]가 끼어들어 발음됨(허용) — 피어[피여]
07

확인 문제

각 단어의 밑줄 친 활용형에 나타난 모음 변동을 생각해 본 뒤, 문제를 클릭해 정답을 확인하세요.

①따르- + -아 → 따라
'ㅡ' 탈락
②보- + -아라 → 봐라
반모음화(ㅗ→[w])
③이기- + -어 → 이기어[이기여]
반모음 첨가([j] 첨가, 표준발음법 제22항)
④건너- + -어 → 건너
동일 모음 탈락
⑤바뀌- + -어 → 바뀌어
변동 없음 — 어간이 'ㅟ'로 끝나 그대로 결합(참고: 실제 발화에서는 [바뀌여]로 반모음 첨가가 일어나기도 하나 표준 발음의 원칙형은 [바뀌어]이다)
⑥담그- + -아 → 담가
'ㅡ' 탈락
⑦다니- + -어라 → 다녀라
반모음화(ㅣ→[j])
⑧되- + -어 → 되어[되어/되여]
반모음 첨가([j] 첨가, 표준발음법 제22항 허용)
⑨서- + -어도 → 서도
동일 모음 탈락
⑩두- + -었다 → 뒀다
반모음화(ㅜ→[w])
해설. 반모음화는 표기 자체가 바뀌는 데 비해(오+아서→와서), 반모음 첨가는 표기(피어, 되어)를 그대로 두고 발음에서만 [여]로 발음하는 것이 허용되는 차이가 있다.
