한글 맞춤법 제57항 퀴즈

소리는 같거나 비슷하지만 뜻이 다른 말 32묶음 · 78문항 — 빈칸에 알맞은 말을 떠올린 뒤 문장을 클릭해 정답과 해설을 확인하세요.
한글 맞춤법 제57항 다음 말들은 각각 구별하여 적는다. (가름/갈음, 거름/걸음, 걷히다/거치다 …)
01

가름 · 갈음

선택할 말: 가름 / 갈음

1.둘로 (　　　　).
가름 — ‘가름’은 나누거나 구별한다는 뜻이에요.
2.새 책상으로 (　　　　)하였다.
갈음 — 다른 책상으로 대신하므로 ‘갈음’이에요.
02

거름 · 걸음

선택할 말: 거름 / 걸음

1.풀을 썩힌 (　　　　).
거름 — 풀을 썩혀 만든 비료이므로 ‘거름’이에요.
2.빠른 (　　　　)으로 걸었다.
걸음 — 걷는 동작이나 발걸음을 뜻하므로 ‘걸음’이에요.
3.농부가 배추밭에 (　　　　)을 주었다.
거름 — 농작물에 주는 비료이므로 ‘거름’이에요.
03

걷히다 · 거치다

선택할 말: 걷히다 / 거치다

1.영월을 (　　　　) 왔다.
거쳐 — 어떤 곳을 지나왔다는 뜻의 ‘거치다’예요.
2.외상값이 잘 (　　　　).
걷힌다 — 받을 돈이 모인다는 뜻의 ‘걷히다’예요.
04

겉잡다 · 걷잡다

선택할 말: 겉잡다 / 걷잡다

1.(　　　　)을 수 없는 상태.
걷잡 — 사태를 억누르거나 진정시킬 수 없다는 뜻이에요.
2.(　　　　)아서 이틀 걸릴 일.
겉잡 — 겉으로 보아 대강 짐작한다는 뜻이에요.
05

그러므로 · 그럼으로(써)

선택할 말: 그러므로 / 그럼으로(써)

1.그는 부지런하다. (　　　　) 잘 산다.
그러므로 — 앞의 내용이 뒤의 결과를 낳으므로 ‘그러니까’와 같아요.
2.그는 열심히 공부한다. (　　　　) 은혜에 보답한다.
그럼으로 — 그렇게 하는 것을 수단으로 삼으므로 ‘그럼으로’예요.
06

노름 · 놀음

선택할 말: 노름 / 놀음

1.(　　　　)판이 벌어졌다.
노름 — 돈이나 재물을 걸고 하는 놀이를 뜻해요.
2.즐거운 (　　　　).
놀음 — 즐기며 노는 일을 뜻하므로 ‘놀음’이에요.
07

느리다 · 늘리다 · 늘이다

선택할 말: 느리다 / 늘리다 / 늘이다

1.진도가 너무 (　　　　).
느리다 — 진행 속도가 더디다는 뜻의 ‘느리다’예요.
2.고무줄을 (　　　　).
늘이다 — 고무줄의 길이를 길게 하므로 ‘늘이다’예요.
3.수출량을 더 (　　　　).
늘리다 — 수출의 양을 많아지게 하므로 ‘늘리다’예요.
08

달이다 · 다리다

선택할 말: 달이다 / 다리다

1.옷을 (　　　　).
다리다 — 옷의 주름을 펴는 것은 ‘다리다’예요.
2.약을 (　　　　).
달이다 — 약재를 물에 넣고 끓여 우려내므로 ‘달이다’예요.
09

다치다 · 닫치다 · 닫히다

선택할 말: 다치다 / 닫치다 / 닫히다

1.부주의로 손을 (　　　　).
다치다 — 몸에 상처를 입는다는 뜻의 ‘다치다’예요.
2.문이 저절로 (　　　　).
닫히다 — 문이 닫는 동작을 당하므로 ‘닫히다’예요.
3.문을 힘껏 (　　　　).
닫치다 — 문을 세게 닫는다는 뜻의 ‘닫치다’예요.
10

맞히다 · 마치다

선택할 말: 맞히다 / 마치다

1.벌써 일을 (　　　　).
마치다 — 일을 끝낸다는 뜻이므로 ‘마치다’예요.
2.여러 문제를 더 (　　　　).
맞히다 — 문제의 답을 옳게 댄다는 뜻이므로 ‘맞히다’예요.
11

목거리 · 목걸이

선택할 말: 목거리 / 목걸이

1.(　　　　)가 덧났다.
목거리 — ‘목거리’는 목이 붓고 아픈 병을 뜻해요.
2.새로 산 (　　　　)가 옷과 잘 어울린다.
목걸이 — 목에 거는 장신구이므로 ‘목걸이’예요.
12

받치다 · 바치다 · 밭치다 · 받히다

선택할 말: 받치다 / 바치다 / 밭치다 / 받히다

1.나라를 위해 목숨을 (　　　　).
바치다 — 목숨을 나라에 드리므로 ‘바치다’예요.
2.우산을 (　　　　) 간다.
받치고 — 우산을 펴서 머리 위에 드는 것은 ‘받치다’예요.
3.쇠뿔에 (　　　　).
받히다 — 소가 뿔로 받는 동작을 당하므로 ‘받히다’예요.
4.술을 체에 (　　　　).
밭치다 — 체로 액체를 걸러 내는 것은 ‘밭치다’예요.
13

반드시 · 반듯이

선택할 말: 반드시 / 반듯이

1.약속은 (　　　　) 지켜라.
반드시 — ‘꼭, 틀림없이’라는 뜻이므로 ‘반드시’예요.
2.고개를 (　　　　) 들어라.
반듯이 — 기울거나 비뚤어지지 않게 하므로 ‘반듯이’예요.
14

부딪치다 · 부딪히다

선택할 말: 부딪치다 / 부딪히다

1.차와 차가 마주 (　　　　).
부딪치다 — 차들이 서로 힘 있게 맞닿는 동작이므로 ‘부딪치다’예요.
2.마차가 화물차에 (　　　　).
부딪히다 — 다른 차가 부딪치는 일을 당하므로 ‘부딪히다’예요.
15

부치다 · 붙이다 (1)

선택할 말: 부치다 / 붙이다

1.힘이 (　　　　) 일이다.
부치는 — 힘이 모자라거나 감당하기 어렵다는 뜻이에요.
2.우표를 (　　　　).
붙인다 — 우표가 봉투에 달라붙게 하므로 ‘붙이다’예요.
3.책상을 벽에 (　　　　).
붙인다 — 책상을 벽에 가까이 닿게 하므로 ‘붙이다’예요.
4.편지를 (　　　　).
부친다 — 편지를 다른 곳으로 보내므로 ‘부치다’예요.
16

부치다 · 붙이다 (2)

선택할 말: 부치다 / 붙이다

1.흥정을 (　　　　).
붙인다 — 흥정이 이루어지도록 중간에서 연결하므로 ‘붙이다’예요.
2.불을 (　　　　).
붙인다 — 불이 옮아 타게 하므로 ‘붙이다’예요.
3.논밭을 (　　　　).
부친다 — 논밭을 이용해 농사짓는 것은 ‘부치다’예요.
4.빈대떡을 (　　　　).
부친다 — 기름을 두르고 익히는 조리이므로 ‘부치다’예요.
17

부치다 · 붙이다 (3)

선택할 말: 부치다 / 붙이다

1.식목일에 (　　　　) 글.
부치는 — 식목일과 관련해 의견을 드러내는 글이므로 ‘부치다’예요.
2.감시원을 (　　　　).
붙인다 — 감시하는 일을 맡겨 곁에 두므로 ‘붙이다’예요.
3.회의에 (　　　　) 안건.
부치는 — 안건을 회의에서 다루도록 넘기므로 ‘부치다’예요.
4.조건을 (　　　　).
붙인다 — 조건을 덧붙인다는 뜻이므로 ‘붙이다’예요.
18

부치다 · 붙이다 (4)

선택할 말: 부치다 / 붙이다

1.취미를 (　　　　).
붙인다 — 어떤 일에 관심과 흥미가 생기게 하므로 ‘붙이다’예요.
2.인쇄에 (　　　　) 원고.
부치는 — 원고를 인쇄하는 일에 넘기므로 ‘부치다’예요.
3.별명을 (　　　　).
붙인다 — 별명을 지어 준다는 뜻이므로 ‘붙이다’예요.
4.삼촌 집에 숙식을 (　　　　).
부친다 — 남의 집에 먹고 자는 일을 의탁하므로 ‘부치다’예요.
19

시키다 · 식히다

선택할 말: 시킨다 / 식힌다

1.인부들에게 일을 (　　　　).
시킨다 — 다른 사람에게 일을 하게 하므로 ‘시키다’예요.
2.끓인 물을 (　　　　).
식힌다 — 물의 온도를 낮추므로 ‘식히다’예요.
20

앎 · 알음 · 아름

선택할 말: 앎 / 알음 / 아름

1.둘레가 세 (　　　　)이나 되는 나무.
아름 — 두 팔로 감싸는 둘레를 세는 단위는 ‘아름’이에요.
2.우리는 전부터 (　　　　)이 있는 사이다.
알음 — 서로 아는 관계를 뜻하므로 ‘알음’이에요.
3.(　　　　)은 삶의 힘이다.
앎 — ‘알다’에 ‘-ㅁ’이 붙어 아는 것을 뜻하는 ‘앎’이에요.
21

앉히다 · 안치다

선택할 말: 앉힌다 / 안친다

1.밥을 (　　　　).
안친다 — 밥을 지으려고 쌀과 물을 솥에 넣는 것은 ‘안치다’예요.
2.윗자리에 (　　　　).
앉힌다 — 사람을 앉게 하므로 ‘앉히다’예요.
22

어름 · 얼음

선택할 말: 어름 / 얼음

1.두 물건의 (　　　　)에서 일어난 현상.
어름 — 두 물건의 경계나 그 부근을 뜻하므로 ‘어름’이에요.
2.(　　　　)이 얼었다.
얼음 — 물이 얼어서 된 것이므로 ‘얼음’이에요.
23

있다가 · 이따가

선택할 말: 있다가 / 이따가

1.(　　　　) 오너라.
이따가 — 조금 뒤의 때를 가리키므로 ‘이따가’예요.
2.돈은 (　　　　)도 없다.
있다가 — 돈이 존재했다가 없어졌다는 뜻이므로 ‘있다가’예요.
24

절이다 · 저리다

선택할 말: 절이다 / 저리다

1.다친 다리가 (　　　　).
저리다 — 감각이 둔해지거나 찌릿한 느낌은 ‘저리다’예요.
2.김장 배추를 (　　　　).
절이다 — 배추에 소금기가 배게 하므로 ‘절이다’예요.
25

졸이다 · 조리다

선택할 말: 졸이다 / 조리다

1.생선을 (　　　　).
조리다 — 양념이 배도록 국물을 줄이며 익히므로 ‘조리다’예요.
2.마음을 (　　　　).
졸이다 — 초조하게 마음을 쓰는 것은 ‘마음을 졸이다’예요.
26

1.여러 날을 (　　　　).
주렸다 — 음식을 먹지 못해 배고프다는 뜻이므로 ‘주리다’예요.
2.비용을 (　　　　).
줄였다 — 드는 돈의 양을 적게 하므로 ‘줄이다’예요.
27

하노라고 · 하느라고

선택할 말: 하노라고 / 하느라고

1.(　　　　) 한 것이 이 모양이다.
하노라고 — 자기 나름대로 노력하여 했다는 뜻을 나타내요.
2.공부(　　　　) 밤을 새웠다.
하느라고 — 공부한 일이 밤을 새운 원인이므로 ‘하느라고’예요.
28

-는 이보다 · -느니보다

선택할 말: -는 이보다 / -느니보다

1.나를 찾아오(　　　　) 집에 있거라.
느니보다 — 앞 행동보다 뒤 행동이 낫다고 비교하는 표현이에요.
2.오(　　　　) 가는 이가 많다.
는 이보다 — 오는 사람과 가는 사람을 비교하므로 ‘이(사람)’를 띄어요.
29

-(으)리만큼 · -(으)ㄹ 이만큼

선택할 말: 하리만큼 / 할 이만큼

1.나를 미워(　　　　) 그에게 잘못한 일이 없다.
하리만큼 — 그 정도에 이를 만큼이라는 뜻의 어미 ‘-리만큼’이에요.
2.찬성(　　　　)이나 반대할 이가 많을 것이다.
할 이만큼 — 찬성할 사람만큼이라는 뜻이므로 ‘이(사람)’를 띄어요.
30

-(으)려 · -(으)러

선택할 말: -(으)려(의도) / -(으)러(목적)

1.공부하(　　) 간다.
러 — ‘가다’의 목적을 나타내므로 ‘공부하러’예요.
2.서울 가(　　) 한다.
려 — 서울에 가려는 의도를 나타내므로 ‘가려’예요.
31

-(으)로서 · -(으)로써

선택할 말: 로서 / 로써

1.사람으(　　　　) 그럴 수는 없다.
로서 — 사람이라는 지위나 자격을 나타내므로 ‘로서’예요.
2.닭으(　　　　) 꿩을 대신했다.
로써 — 꿩을 대신하는 수단이나 재료이므로 ‘로써’예요.
32

(-ㅁ, -음)으로(써) · -(으)므로

믿으므로 — ‘믿기 때문에’라는 이유를 나타내므로 ‘믿으므로’예요.
2.그는 (　　　　) 산 보람을 느꼈다.
믿음으로 — 믿는 것을 수단으로 삼으므로 ‘믿음으로’예요.
